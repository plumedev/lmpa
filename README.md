# Nuxt + Nuxt UI + Three.js + Rapier Physics

Application initialisée avec **Nuxt 4**, **Nuxt UI v4**, **TypeScript**, **Three.js**, **TresJS** et **Rapier 3D Physics**.

## 🚀 Démarrage rapide

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Vérifier les types TypeScript
npm run typecheck

# Linter le code
npm run lint

# Construire pour la production
npm run build
```

## 🛠️ Stack technique

- **[Nuxt 4](https://nuxt.com/)** - Framework Vue.js full-stack moderne
- **[Nuxt UI v4](https://ui.nuxt.com/)** - Composants d'interface basés sur Tailwind CSS v4 et Reka UI
- **[Three.js](https://threejs.org/)** - Moteur de rendu 3D WebGL / WebGPU
- **[TresJS](https://tresjs.org/)** (`@tresjs/nuxt`, `@tresjs/core`, `@tresjs/cientos`) - Intégration déclarative 3D pour Vue/Nuxt
- **[Rapier 3D](https://rapier.rs/)** (`@tresjs/rapier`, `@dimforge/rapier3d-compat`) - Moteur physique 3D temps-réel (Rust/WebAssembly)
- **[TypeScript](https://www.typescriptlang.org/)** - Typage statique strict
- **[ESLint](https://eslint.org/)** - Qualité et cohérence de code
